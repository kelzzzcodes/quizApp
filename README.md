# Ronaldo Quiz App

## 📋 Assignment Instructions
You are tasked with building a **Quiz Application** with the following features:

- Display **one question at a time**.
- Allow users to **select an answer** and then **click the "Next" button** to move forward.
- **Show the total score** at the end of the quiz.
- Perform **DOM actions** like:
  - Update question text and options dynamically.
  - Change button styles based on correct or wrong answers.
  - Track and validate the user's selected choices.


## 🚀 How to Run the Project

1. **Clone or download** the project files.
2. **Open `index.html`** in any modern web browser (e.g., Chrome, Firefox).
3. The quiz will **prompt for your name** and start automatically.
4. **Answer each question** by clicking an option.
5. **Click "Next"** to proceed to the next question.
6. After the last question, your **total score** will be displayed!

---

## ✨ Features Implemented

- **Shuffled Questions and Options:** Every quiz session has random question and option order.
- **Username Capture:** Users are greeted and their name appears in the final score.
- **Answer Validation:** Correct answers highlight green, wrong answers highlight red.
- **Score Tracking:** Real-time score calculation as the user proceeds.
- **Error Handling:** Users are warned if they try to click "Next" without selecting an answer.


## 📚 Technologies Used

- HTML5
- CSS3
- JavaScript (DOM manipulation, event handling)
